## What exists

src/motodiag/cli/shop.py registers the shop command group and imports the sub-groups, including shop_inventory and shop_warranty. src/motodiag/cli/shop_inventory.py and the inventory package provide item and vendor repositories (add, get, adjust quantity, vendors), which the bike-inventory import would need to feed. The first-time shop profile wizard (name, address, phone, email) is recorded in docs/phases/completed/160_implementation.md and lives in the shop command group in src/motodiag/cli/shop.py. Customer creation is in the shop customer commands, recorded in the same implementation log. The diagnostic workflow, with its predefined templates and walkthrough simulations, is recorded in docs/phases/completed/82_implementation.md. The census's src hits for the import term are module imports of inventory, not an import feature. The src hits for the first-diagnostic term are knowledge-seed text, not a walkthrough. Nothing in src is an onboarding flow, a staff setup, or a bike import.
