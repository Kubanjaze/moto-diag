## What exists

The gateway in src/motodiag/payments/stripe_api.py pins stripe==16.0.0, which sends API version 2026-09-30.endive. Per Phase 273's handoff, it refuses a live key or live event unless the environment is prod, and it scrubs key-shaped text from its errors. The webhook intake is stripe_webhook in src/motodiag/api/routes/billing.py, which reads the Stripe-Signature header and verifies the raw body. Tests that sign payloads and post them through that route are in tests/test_phase273_invoice_payments.py. Phase 176's subscription path was repaired under F187 so that a tier change re-reads the subscription from Stripe. The Sentry DSN setting in telemetry/dsn.py, from Phase 343's log, is the existing place a monitor check-in would read its address from. Nothing yet in src shows a poller, a live-mode event source, a monitor check-in, a limit check or an upgrade guide.
