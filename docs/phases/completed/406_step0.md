## S0-2 — the lock

`ops/desktop/install_remote.sh` (102 lines) writes
`/etc/ssh/sshd_config.d/10-motodiag-ops.conf` (lines 50–61):
`AllowUsers lilcu@<the Mac's tailnet address>`, `AuthenticationMethods
publickey`, `DisableForwarding yes`, `PermitTTY no`, `ForceCommand
/usr/local/libexec/motodiag-remote`; and one key line, `restrict,from=
"<the Mac>",command="<the dispatcher>"` (line 89). The dispatcher is
installed root-owned (lines 45–46), so a branch pulled on the desktop
cannot change what the key runs. **`PermitTTY no` means no request has a
terminal**: `through_fleet.ask_tty` (`.claude/skills/deploy/through_fleet.py`
lines 277–285) opens `/dev/tty`, so the database step cannot ask for yes
through the way in. The step must be two calls, with the yes asked on the
Mac between them.
