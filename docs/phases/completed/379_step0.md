## S0-2: decisions, not stops

No item offers two plans that would ship different things, so there is no
stop. Taken here, with the reason:
- **F176:** the refusal names every table whose foreign key to `vehicles`
  would block the delete, read from the schema (`PRAGMA
  foreign_key_list`), not the two the finding names. A table added later
  joins by itself.
- **F193:** a helper converts the typed value with `utc_cutoff` and writes
  it as `YYYY-MM-DDTHH:MM:SS+00:00`, with no fraction. In text order `+`
  sorts before `.`, so a sample stamped exactly on the second still meets
  `>=`. The comparison stays on the column, so its index is kept.
- **F154:** a new lookup entry, "Fiddle 50", cited to its own service
  manual's cover and specification table, rather than an alias on the
  Fiddle III entry as the triage suggested. The 50 has its own book, and a
  separate entry keeps F131's rule that a canonical name resolves to its
  own entry.
- **F131:** resolution also matches an entry's own canonical name, and a
  guard over every entry requires it to resolve to itself. 255B's pin of
  the six is inverted. The Like 50i and 125 gap moves to a finding of its
  own, F199, so closing F131 drops nothing (as F119 → F198).
- **F155:** a stated plural rule in `relevance_tokens` ("ies" → "y";
  "ches", "shes", "sses", "xes" → drop "es"; otherwise a final "s" after
  four letters, but not "ss", "us" or "is"). Its effect on ranking is
  measured over a fixed set of machines and symptoms before and after,
  and recorded.
- **F197:** `verify-live` exits 3 when live differs from the approved diff
  and says whether live's schema is past the phase's own migrations. Check
  8 fails verify_phase on any exit but 0 and 2 ("no deploy"). Every other
  check stays print-only, as before.
- **F173:** `wholetree.py` keeps pytest's whole output in a log under
  `.git/motodiag_wholetree/`, prints every FAILED and ERROR line and the
  log's path, then F173 closes on a stated count of regressions of record
  in which the test passed.
- **F144:** a `powertrain` field on `VehicleContext`, filled from the
  vehicle row as 257B fills `transmission`. Gate 11 shows whether the
  snapshot moves; S0-1 says it should not.
