## Decision (recorded, not a stop)

The check that a suite run left the real ledger alone cannot be "the file
is byte for byte the same": on this machine the fleet appends real calls
while tests run. It fails when the bytes that were there changed, or when
an appended row's session is not named in one of the fleet's run folders,
which a test cannot make (no test reaches the network or a real `claude`;
the network guard, Phase 281). This needs no new field, so it holds
against the fleet's copy before it moves to this code.
