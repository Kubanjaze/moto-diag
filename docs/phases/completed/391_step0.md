## S0-1. verify_phase.sh's fourteen checks, read for a fleet-built PR

`verify_phase.sh <PHASE> <REG_HASH> <TIP>` is the operator's check **after
a merge**: it reads `origin/master` and live. Before a merge, on a PR's
head in the fence (no network, no token, no `/home`), some of its checks
cannot pass by design, and its exit code is set by check 8 alone (F197).
So the Quartermaster never reads its exit code: it reads each check's
section, by the rule in the third column. Measured in the fence on PR #20's
head (`f987bf3`, phase 390A), ``verify_phase.sh 390A 44f846d f987bf3`, run with no model and no token
(`fixtures/quartermaster/pr20/verify.txt`; 36 s with the fleet's
virtualenv bound, exit 1 from check 8)`:

| # | the check | before the merge, in the fence | the Quartermaster's reading |
|---|---|---|---|
| 1 | master pushed, tree clean | the TIP is not on `origin/master` (it is not merged); the fetch has no network | not read; its own **Q9** instead: the clone is clean and the PR head merges onto `master` with no conflict (`git merge-tree`) |
| 2 | no code after the regression hash | runs | passes only on `none (docs only)` |
| 3 | docs in completed | runs | the phase's files listed, none in `in_progress/` |
| 4 | stubs (`TODO`, `TBD`, `placeholder`, `fill in`) | runs | each hit goes to the model, which says stub or prose (390's one hit was prose); the scripted stub rule is **Q7** |
| 5 | deviations, bug-fix register (A4) | runs | a Deviations heading and `A4 ok` |
| 6 | the row's words | runs | `within cap` |
| 7 | the findings header | prints a line, no verdict | not read; check 13 holds B1 |
| 8 | schema and live | no live in the fence: `"CHECK 8 FAILED: live is not on this machine, and live-check through the way in exited 4"` | not read: **Q1** refuses any phase with a migration or a deploy before the runs |
| 9 | backup | `prints nothing` | not read, as 8 |
| 10 | targeted tests (`-k PHASE`) | runs | a pytest summary line, and no `failed` or `error` |

| 13 | findings resolve | runs | `every cited F-number resolves` |
