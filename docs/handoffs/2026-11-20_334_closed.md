## What shipped

- **The two texts,** `docs/legal/terms.md` and `docs/legal/privacy.md`,
  Version 1.0 — 2026-11-19, adapted from Basecamp's policies (CC BY 4.0),
  each ending with the attribution. The terms say in plain words: the
  mechanic decides and answers for the repair; the tax figures are a
  convenience and the shop answers for its own sales tax; the shop answers
  for its customers' claims; Mekno's liability to a shop is capped at the
  fees the shop paid in the 12 months before the claim; the shop's data is
  the shop's; a subscription's price and renewal are shown before it is
  paid, and it is cancelled online. The privacy policy names the seven
  services data goes to: Stripe, Anthropic, OpenAI (Whisper), Sentry,
  Backblaze, Apple push and NHTSA. `docs/legal/README.md` says how a new
  version is made.
- **Who accepted which version, and when:** the table `terms_acceptances`
  (migration 091), `GET /v1/terms` (the version, its date and the two
  pages' addresses; signed in, whether the caller accepted) and
  `POST /v1/terms/accept`. A stale version is 422 `terms-version-stale`;
  a new version must be accepted again.
- **Two switches, both off:** `MOTODIAG_TERMS_REQUIRED` refuses every
  route that takes a credential, the knowledge-base routes included, with
  403 `terms-not-accepted` until the current version is accepted (four
  routes stay reachable: read the terms, accept, who am I, log out);
  `MOTODIAG_CHECKOUT_TERMS_CONSENT` makes Stripe Checkout ask for the
  terms. With both off, nothing a user does today changes.
- **The app's screen is 334B,** a 🔲 row with its prompt
  `docs/prompts/334B_the_apps_terms_screen.txt`. The live WebSocket route
  resolves its credential itself and is the one credentialed route the
  first switch does not hold; named for 334B.

### Step 1: put the server on the new code, with both switches off

**Which computer:** the home desktop. **Which window:** the Ubuntu
terminal. Run it after the pull request is merged. It takes about a
minute, and asks for your Ubuntu password once.

What it does, in order:
1. **Checks before changing anything.** The server must be running, its
   copy of the code clean and on master, GitHub's master must hold this
   phase, live must already have the new table, and the server's settings
   must not turn either new switch on.
2. **Brings the copy up to date** (fast-forward only).
3. **Restarts the server** and waits for it to answer healthy.
4. **Reads the new terms address once** and checks it gives version 1.0
   and the two page addresses.

If the server does not come back, the code is put back and the server is
restarted on it.

```bash
bash <<'EOF2'
set -u
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
SRV=~/motodiag/server
LIVE=~/motodiag/live
ENVF=~/.config/motodiag/server.env
API=motodiag-api.service
FIX=6d12ab768d25e51b7204e0f32f5c69d6d25ec799
healthy() {
  for i in $(seq 30); do
    curl -s --max-time 5 http://127.0.0.1:8000/healthz </dev/null | grep -q '"status":"ok"' && return 0
    sleep 2
  done
  return 1
}

echo "Checking the server, its settings and live..."
for T in git systemctl sudo curl python3 sleep grep seq; do
  command -v "$T" >/dev/null 2>&1 || bad "this computer has no $T command; nothing was changed, so bring this to the advisor"
done
{ [ -d "$SRV/.git" ] && [ -f "$LIVE/motodiag.db" ] && [ -f "$ENVF" ]; } || bad "this is not the computer the server runs on (run it on the home desktop, in the Ubuntu window); nothing was changed"
systemctl is-active -q "$API" </dev/null || bad "the server is not running right now; nothing was changed, so bring this to the advisor"
grep -Eq '^[[:space:]]*(export[[:space:]]+)?MOTODIAG_(TERMS_REQUIRED|CHECKOUT_TERMS_CONSENT)[[:space:]]*=' "$ENVF" && bad "the server's settings file already has one of the two new terms switches in it; they must stay off for now, so nothing was changed: bring this to the advisor"
TABLE=$(python3 -c '
import sqlite3, sys
db = sqlite3.connect("file:" + sys.argv[1] + "?mode=ro", uri=True)
print("yes" if db.execute("SELECT 1 FROM sqlite_master WHERE type = ? AND name = ?", ("table", "terms_acceptances")).fetchone() else "no")' "$LIVE/motodiag.db" </dev/null) || bad "live could not be read; nothing was changed, so bring this to the advisor"
[ "$TABLE" = yes ] || bad "live does not have the new table for the terms yet; nothing was changed, so bring this to the advisor"
[ "$(git -C "$SRV" branch --show-current </dev/null)" = master ] || bad "the server's copy of the code is not on master; nothing was changed, so bring this to the advisor"
[ -z "$(git -C "$SRV" status --porcelain --untracked-files=no </dev/null)" ] || bad "the server's copy of the code has changes made by hand; nothing was changed, so bring this to the advisor"
BEFORE=$(git -C "$SRV" rev-parse HEAD </dev/null)
git -C "$SRV" fetch -q origin +refs/heads/master:refs/remotes/origin/master </dev/null || bad "could not fetch from GitHub; nothing was changed"
TARGET=$(git -C "$SRV" rev-parse origin/master </dev/null)
git -C "$SRV" merge-base --is-ancestor "$FIX" "$TARGET" </dev/null || bad "master on GitHub does not have this phase yet: merge the pull request first, then paste this block again; nothing was changed"
git -C "$SRV" diff --quiet "$FIX" "$TARGET" -- src pyproject.toml </dev/null || bad "master has new code since this phase that has not been checked here; nothing was changed, so bring this to the advisor"
git -C "$SRV" merge-base --is-ancestor "$BEFORE" "$TARGET" </dev/null || bad "the server's copy of the code has commits that are not on master; nothing was changed, so bring this to the advisor"
if [ "$BEFORE" = "$TARGET" ]; then
  echo "The server's copy of the code is already up to date."
else
  echo "Bringing the server's copy of the code up to date..."
  git -C "$SRV" merge -q --ff-only "$TARGET" </dev/null || bad "could not bring the server's copy of the code up to date; nothing was changed"
fi

echo
echo "Your Ubuntu password, once, to restart the server (only the code has changed so far):"
sudo -v </dev/null || { git -C "$SRV" reset -q --keep "$BEFORE" </dev/null; bad "sudo did not take the password; the code was put back as it was and nothing was restarted"; }
putback() {
  echo "Putting the server back on the old code..."
  git -C "$SRV" reset -q --keep "$BEFORE" </dev/null
  sudo systemctl restart "$API" </dev/null
  healthy && bad "$1. The server is back on the old code and running; bring this to the advisor"
  bad "$1, and the server is not running even on the old code: bring this to the advisor now"
}

echo "Restarting the server (up to 60 seconds)..."
sudo systemctl restart "$API" </dev/null || putback "the server could not be restarted"
healthy || putback "the server did not come back healthy on the new code"
echo "The server is healthy on the new code."

echo "Reading the terms address once..."
SAYS=$(curl -s --max-time 10 http://127.0.0.1:8000/v1/terms </dev/null)
printf '%s\n' "$SAYS" | python3 -c '
import json, sys
d = json.load(sys.stdin)
assert d["version"] == "1.0", d
assert d["terms_url"] and d["privacy_url"], d
print("    version " + d["version"] + " of " + d["date"])
print("    terms:   " + d["terms_url"])
print("    privacy: " + d["privacy_url"])' || bad "the server is on the new code but the terms address did not answer as it should (it said: $SAYS); bring this to the advisor"
echo "The server is on: $(git -C "$SRV" log -1 --format='%h %s' </dev/null)"
echo "ALL GOOD"
EOF2
```
