## After the merge: #14 picks up again

**Which computer:** the home desktop. **Which window:** the Ubuntu
terminal. Paste this whole block once the merge to `master` is pushed.
It waits for any test run of the fleet's to finish first, then moves the
fleet onto `master`, restarts it and lets #14 go on. It can take up to 12
minutes.

```bash
bash <<'EOF'
set -u
LOG=~/.local/state/motodiag/fleet/dispatcher.log
CODE=~/motodiag/fleet/code
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
if pgrep -x bwrap >/dev/null; then bad "the fleet is busy right now; wait 15 minutes and paste this again"; fi
git -C "$CODE" fetch -q origin master </dev/null || bad "could not fetch from GitHub"
git -C "$CODE" checkout -q master </dev/null || bad "could not switch the fleet to master"
git -C "$CODE" merge -q --ff-only origin/master </dev/null || bad "could not bring the fleet up to date"
grep -q "def stage_recheck" "$CODE/.claude/skills/fleet/dispatcher.py" || bad "the fleet's copy does not have this phase's code yet"
START=$(wc -l < "$LOG")
PID=$(systemctl show -p MainPID --value motodiag-fleet.service)
[ "$PID" -gt 0 ] || bad "the fleet is not running"
kill -TERM "$PID" || bad "could not restart the fleet"
echo "Restarting the fleet (about 30 seconds)..."
for i in $(seq 60); do tail -n +$((START+1)) "$LOG" | grep -q "the search on start:" && break; sleep 2; done
tail -n +$((START+1)) "$LOG" | grep -q "the search on start:" || bad "the fleet did not come back"
gh issue edit 14 --remove-label needs-admiral </dev/null >/dev/null || bad "could not take the hold off issue 14"
echo "Waiting for the fleet to pick issue 14 up (up to 10 minutes)..."
for i in $(seq 60); do tail -n +$((START+1)) "$LOG" | grep -q "issue 14: the model-free run on e15b46278cc0" && break; sleep 10; done
tail -n +$((START+1)) "$LOG" | grep -q "issue 14: the model-free run on e15b46278cc0" || bad "issue 14 was not picked up"
echo
echo "The fleet is on: $(git -C "$CODE" log -1 --oneline)"
echo "ALL GOOD"
EOF
```

When it prints ALL GOOD, the fleet is checking #14's work again. That
check takes about 40 minutes; the Red Team follows on its own.
