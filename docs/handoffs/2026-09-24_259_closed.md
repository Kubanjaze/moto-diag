## What 259 learned that the next phase should not relearn

- **F124's guard must be in the sandbox run list** — this session ran it
  because the operator listed it, and it caught two head-literal pins
  before any commit could carry them to the regression. In 258 the same
  guard was not in the list and the pin reached the regression of
  record (its fix #5, `0533038`). Instruction 6 of this session's brief
  is the rule that worked; keep it for the third run.
- **SQLite does not concatenate adjacent string literals.** The
  migration's first shape used PostgreSQL-style `'…' '…'`
  continuation; it is a syntax error in SQLite, and each long item text
  must be one literal per line (apostrophes doubled). Caught by the
  first test run.
- **The session's exported `PYTHONPATH` breaks clean-venv tests
  structurally** — pip inside the venv sees the source tree as the
  package and installs no console script, so `test_phase209_packaging`
  cannot pass under it, at any commit. Any future sandbox session should
  treat that file's result as environmental, and prove it so the way this
  phase did: identical failures at the base commit in a worktree.
- **A content pin must demand its needle per field, not per item.**
  The probe that caught it is three lines: corrupt one field's figure
  and watch the pin. Worth keeping for any phase that pins seeded prose.
