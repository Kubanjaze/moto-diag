## What shipped

In `moto-diag-mobile`, pull request #12 (head `e71fd74`), built by the
operator's own session and merged by the operator as `58142e4`:
- **The terms box.** When the server refuses a call because the user has
  not accepted the current terms, a box opens over any screen. It shows
  the version and its date, opens the terms and the privacy policy in the
  phone's browser, and records "I agree" with the version shown. If the
  terms changed while it was open, it shows the new version and says so.
- **Only when the server asks.** The box opens on the server's refusal,
  once however many calls were refused, and never at start-up, so with the
  switch off nobody is asked (K128).

  and the box: a sign-in is ended on the server, and a pasted key is only
  cleared.
- **"Sign in first."** replaces "Set an API key first." on the home
  screen.
