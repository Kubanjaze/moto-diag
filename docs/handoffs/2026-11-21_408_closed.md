### Step 2: make the upload file (the Mac, the Terminal window)

Only after the pull request is merged. Paste this block. It fetches master
and writes one file, `getmekno-site-408.zip`, into your Downloads folder.

```bash
bash <<'EOF1'
set -u
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
cd ~/Projects/moto-diag || bad "there is no moto-diag folder in Projects on this Mac"
git fetch -q origin master || bad "could not reach GitHub"
git ls-tree -r --name-only origin/master -- site/ | grep -q '^site/terms/index.html$' || bad "master has no site/ yet: is the pull request merged?"
OUT="$HOME/Downloads/getmekno-site-408.zip"
rm -f "$OUT"
git archive --format=zip -o "$OUT" origin/master:site || bad "could not build the upload file"
echo "Built from master at $(git rev-parse --short origin/master):"
unzip -l "$OUT"
shasum -a 256 "$OUT"
for f in _headers index.html sitemap.xml terms/index.html privacy/index.html thanks/index.html; do
  unzip -l "$OUT" | grep -q " $f\$" || bad "$f is missing from the upload file"
done
echo "The upload file is in Downloads: getmekno-site-408.zip"
echo "ALL GOOD"
EOF1
```

### Step 3: upload it, then add the www redirect (any computer, a browser, Cloudflare)

On your own Cloudflare login. If a screen looks different from these
steps, stop and say so in the project thread.

1. Open the Cloudflare dashboard, then **Workers & Pages**, then the
   project **getmekno**.
2. Click **Create deployment**. Leave it on **Production**.
3. Drag `getmekno-site-408.zip` from Downloads into the upload box, then
   click **Save and Deploy**.
4. Now the redirect. Go back to the dashboard's home and open the domain
   **getmekno.com**, then **Rules**, then **Redirect Rules**, then
   **Create rule**.
5. Name it `www to getmekno.com`. Under "If incoming requests match", pick
   **Custom filter expression**: Field **Hostname**, Operator **equals**,
   Value `www.getmekno.com`.
6. Under "Then", pick **Dynamic**. Expression:
   `concat("https://getmekno.com", http.request.uri.path)`.
   Status code **301**. Tick **Preserve query string**.
7. Click **Deploy**.

If anything goes wrong after step 3, the way back is the project's
**Deployments** list: the previous deployment's menu has **Rollback**.

### Step 4: check what is live (the Mac, the Terminal window)

Paste this block a minute after step 3. It only reads.

```bash
bash <<'EOF2'
set -u
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
cd ~/Projects/moto-diag || bad "there is no moto-diag folder in Projects on this Mac"
git fetch -q origin master || bad "could not reach GitHub"
for f in $(git ls-tree -r --name-only origin/master -- site/ | sed 's#^site/##'); do
  [ "$f" = "_headers" ] && continue
  url="https://getmekno.com/$f"; url="${url%index.html}"
  want=$(git show "origin/master:site/$f" | shasum -a 256 | cut -c1-64)
  got=$(curl -sL --max-time 20 "$url" </dev/null | shasum -a 256 | cut -c1-64)
  [ "$want" = "$got" ] || bad "$url is not the file on master: is the upload done?"
  echo "same as master: $url"
done
CSP="content-security-policy: default-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'none'; frame-ancestors 'none'; base-uri 'self'; form-action 'none'"
for url in https://getmekno.com/ https://getmekno.com/terms/ https://getmekno.com/robots.txt https://getmekno.com/sitemap.xml https://getmekno.com/no-such-page/; do
  H=$(curl -sI --max-time 20 "$url" </dev/null | tr -d '\r' | tr 'A-Z' 'a-z')
  printf '%s\n' "$H" | grep -qxF "$(printf '%s' "$CSP" | tr 'A-Z' 'a-z')" || bad "$url: the content security header is not today's"
  printf '%s\n' "$H" | grep -qx 'strict-transport-security: max-age=31536000' || bad "$url: the secure-only header is missing"
  printf '%s\n' "$H" | grep -q '^set-cookie' && bad "$url sets a cookie"
  echo "headers right: $url"
done
for path in "" support/ terms/ privacy/; do
  code=$(curl -s -o /dev/null -w '%{http_code}' --max-time 20 "https://getmekno.com/$path" </dev/null)
  [ "$code" = "200" ] || bad "https://getmekno.com/$path answered $code"
done
echo "The four pages in the sitemap answer."
R=$(curl -s -o /dev/null -w '%{http_code} %{redirect_url}' --max-time 20 "https://www.getmekno.com/terms/?x=1" </dev/null)
[ "$R" = "301 https://getmekno.com/terms/?x=1" ] || bad "www does not send people to getmekno.com yet (it said: $R)"
echo "www sends people to getmekno.com."
curl -s --max-time 20 https://getmekno.pages.dev/ </dev/null | grep -q '<link rel="canonical" href="https://getmekno.com/">' || bad "the pages.dev copy does not name getmekno.com as the real address"
echo "ALL GOOD"
EOF2
```
