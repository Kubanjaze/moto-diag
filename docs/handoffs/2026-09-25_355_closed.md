  `-p no:xdist`.

  loses that flag, if `addopts` gains `-n`, if the command drifts out of
  the skill, CLAUDE.md, the script or `verify_phase.sh`, or if a parallel

**Speed.** Serial took 30:33 at `c6d3f3a` by pytest's clock. The wall
was 49:40, because the Mac slept 21 minutes, and pytest's clock does not
count sleep. Parallel took 13:26 back to back that morning, and 13:28 for
the regression of record: **2.3×**. On the same tree in the afternoon,
P1 took 24:37 and P2 26:50. In that state `kernel_task` held 63% CPU and
each worker only 25–35%, and Low Power Mode is on for AC power. Those
are the operator's machine settings, and 355 changed neither.

**Parity**, proved and not asserted:
- junit diff: every serial pass passes in parallel, and the parallel runs
  add only 355's 13 new IDs;
- P1, P2 and the regression of record have identical passed sets;
- a planted failure is reported by a 10-worker run;
- all 325 test files pass alone, each in a fresh process;
- the 12 files 355 changed pass serially: 516 passed.

**Two bug fixes.** No test was skipped or marked serial-only.
1. `8b298c1`: 8 hardware CLI tests (146 × 7, 143 × 1) read the process's
   default DB, which only an earlier test had initialised. An order
   dependence, reproduced serially.
2. `003058c`: F124's and 256's scanner controls planted probe files into
   the real `tests/` and `src/motodiag/`. In parallel a probe vanished
   mid-read. The scanners now take the directory, and the controls plant
   into `tmp_path`. Three full parallel runs had passed; a small run
   exposed it.

## What is open

- **A5 does not require the command.** `regression.sh` writes it into
  the line, and `verify_phase.sh` check 14 shows whether it is there.
  Requiring it in `closeout_check.py` A5, from phase 355 on, changes an
  artefact's definition. That is a rule-1 stop, so it was not done. It is
  for the operator's process-kinks pass.
- **The speed-up is capped by the machine, not by the suite.** The
  workers wait on I/O and throttling. Two candidates, both outside 355's
  scope:
  - Low Power Mode off on AC. This is the operator's setting.
  - Test DBs on a RAM disk, or relaxed fsync under tests. The suite
    builds thousands of migrated SQLite files.
- **Within-file order dependence** is checked only by the consecutive
  runs agreeing. The per-file sweep closes the between-files case.
- Nothing to deploy: no `src/` change, no migration. The live DB was
  `195bd383…` before and after every run.
