## After the merge

**Which computer:** the home desktop. **Which window:** the Ubuntu
terminal. Paste this whole block. It checks the fleet is not in the middle
of something, moves the fleet's own copy of the code onto the merged
version, restarts the fleet, and waits for it to say it is back. It does
not touch any issue.

```bash
bash <<'EOF2'
set -u
LOG=~/.local/state/motodiag/fleet/dispatcher.log
CODE=~/motodiag/fleet/code
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
if pgrep -x bwrap >/dev/null; then bad "the fleet is busy right now; wait 15 minutes and paste this again"; fi
STATE=$(gh pr view phase-396-the-fleets-four-slips -R Kubanjaze/moto-diag --json state --jq .state </dev/null) || bad "could not ask GitHub about the pull request"
[ "$STATE" = "MERGED" ] || bad "the pull request is not merged yet (GitHub says: $STATE)"
echo "Moving the fleet onto the merged code..."
git -C "$CODE" fetch -q origin master </dev/null || bad "could not fetch from GitHub for the fleet"
git -C "$CODE" checkout -q master </dev/null || bad "could not switch the fleet to master"
git -C "$CODE" merge -q --ff-only origin/master </dev/null || bad "could not bring the fleet up to date"
grep -q "shlex.join(command)" "$CODE/.claude/skills/fleet/dispatcher.py" || bad "the fleet's copy does not have this phase's code"
grep -q "def plan_approved_at" "$CODE/.claude/skills/fleet/dispatcher.py" || bad "the fleet's copy does not have this phase's code"
START=$(wc -l < "$LOG")
sudo systemctl restart motodiag-fleet.service || bad "could not restart the fleet"
echo "Restarting the fleet (up to 2 minutes)..."
for i in $(seq 60); do tail -n +$((START+1)) "$LOG" | grep -q -E "the search on start:|resume" && break; sleep 2; done
tail -n +$((START+1)) "$LOG" | grep -q -E "the search on start:|resume" || bad "the fleet did not come back"
echo "The fleet said: $(tail -n +$((START+1)) "$LOG" | grep -E "the search on start:|resume" | head -1)"
echo "The fleet is on: $(git -C "$CODE" log -1 --oneline)"
echo "ALL GOOD"
EOF2
```
