### Step 1: put the fleet on the new code, with its new open-file limit

**Which computer:** the home desktop. **Which window:** the Ubuntu
terminal. Paste this whole block once 392 is merged to `master`. It asks
for your password once (to install the fleet's service file). It waits
for nothing: if the fleet is busy it says so and stops.

```bash
bash <<'EOF'
set -u
LOG=~/.local/state/motodiag/fleet/dispatcher.log
CODE=~/motodiag/fleet/code
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
if pgrep -x bwrap >/dev/null; then bad "the fleet is busy right now; wait 15 minutes and paste this again"; fi
git -C "$CODE" fetch -q origin master </dev/null || bad "could not fetch from GitHub"
git -C "$CODE" checkout -q master </dev/null || bad "could not switch the fleet to master"
git -C "$CODE" merge -q --ff-only origin/master </dev/null || bad "could not bring the fleet up to date"
grep -q "def stage_next" "$CODE/.claude/skills/fleet/dispatcher.py" || bad "the fleet's copy does not have this phase's code yet"
sudo sh "$CODE/ops/desktop/install_fleet_unit.sh" || bad "the service file did not install"
START=$(wc -l < "$LOG")
sudo systemctl restart motodiag-fleet.service || bad "could not restart the fleet"
echo "Restarting the fleet (about 30 seconds)..."
for i in $(seq 60); do tail -n +$((START+1)) "$LOG" | grep -q "the search on start:" && break; sleep 2; done
tail -n +$((START+1)) "$LOG" | grep -q "the search on start:" || bad "the fleet did not come back"
PID=$(systemctl show -p MainPID --value motodiag-fleet.service)
LIMIT=$(awk '/Max open files/ {print $4}' /proc/$PID/limits)
echo "The fleet's open-file limit is now: $LIMIT"
[ "$LIMIT" = "1048576" ] || bad "the open-file limit is $LIMIT, not 1048576"
echo "The fleet is on: $(git -C "$CODE" log -1 --oneline)"
echo "ALL GOOD"
EOF
```

### Step 2: let issue 14's Red Team run once more (F228's proof)

terminal. After step 1 printed ALL GOOD. It puts issue 14's review label

```bash
bash <<'EOF'
set -u
LOG=~/.local/state/motodiag/fleet/dispatcher.log
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
START=$(wc -l < "$LOG")
gh issue edit 14 -R Kubanjaze/moto-diag --remove-label review:open </dev/null >/dev/null || bad "could not take the label off issue 14"
gh issue edit 14 -R Kubanjaze/moto-diag --add-label review:open </dev/null >/dev/null || bad "could not put the label back on issue 14"
echo "Waiting for issue 14's Red Team (up to 40 minutes)..."
for i in $(seq 240); do tail -n +$((START+1)) "$LOG" | grep -E -q "issue 14: (clear|back|stopped)" && break; sleep 10; done

[ -n "$RESULT" ] || bad "issue 14's Red Team did not finish in 40 minutes"
echo "$RESULT" | grep -q "leaves a wording defect open with no finding" && bad "the round stopped on the old wording problem"
```
