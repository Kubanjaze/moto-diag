## Standing rules a fresh session needs

**Process**
- Work on `phase-257-orchestrator`, never `master`. Commit and push each
  step, **one make per commit** for writes, and each code change in its own
  commit.
- Put the pass line in the commit message: re-run the related suites after
  the last edit and quote the result. Write messages through a quoted
  heredoc (`<<'MSGEOF'`).
- Every change gets fixtures and break-it: plant the known-bad case, watch
  it go red on the old code, and break each part of the fix on purpose. A
  check never seen to fail is not evidence.
- Run the 244G scanner over the whole of `tests/` before a regression:
  `scan_for_raw_source_assertions(pathlib.Path("tests"))`.
- **Never loosen a check without an operator decision.** Tightening still
  gets reported.
- Targeted edits only on source and tests: no `re.sub` or `sed -i`
  surgery, and read the region before and after.
- Bug fixes get a dated `Bug fix #N` log entry (Issue, Root cause, Fix,
  Files, Verified, Commit). **Six so far share one cause:** each was
  verified against something written by hand rather than against the
  artefact it meets in use. Check against the real document, the real
  census, the real model output and the tool's own output. Write the log
  after the result, never before.

**Running a make**
- Report before the next make.
- A test that uses a machine as "an unknown example" must use a spelling
  **absent from the junction** (`"ZZ-0 unlisted"`) and first assert it is
  still unknown.

**Stops**
- The stops are systemic only:
  - a source-stage error, or the wrong model serving;
  - more than 2 source turns (`SOURCE_MAX_TURNS`);
  - over 150K tokens per spelling sent;
  - over 300K refute tokens per finding;
  - a blocked rate over 50%;
  - refute killing more than 25%.
- Anything else about one finding is `withheld` and never blocks the
  batch's other findings.

**What writes**
- A finding writes only when refute says `kept` with `names_model` true
  **and** the script agrees: `model_scope == "model"`, or refute's
  `model_line` is verifiably on the page (the 4609 rule).
- Family evidence writes nothing.
- The only named exception is the ABS one: a page for "<exact model> ABS".
  Never a transmission variant (DCT, Y-AMT, E-Clutch).

**E12** (a `manual` finding needs mechanism evidence)
- The quote must name a rider-operated clutch, a foot-shift pattern, or
  the word "manual". A gear count, "constant mesh" or "close-ratio" is not
  enough.
- The sentence must carry no automated marker.
- The term must not be negated within 5 words before it or 4 words after.
  `n't` and `cannot` count as negation, and curly apostrophes read as
  straight ones.
- Every E12 rejection carries a reader-miss note. A miss counts only on a
  page whose `model_scope` is "model".
- Re-source reader misses; never loosen E12 for them.

**Credentials and data**
- No credential goes to another route's host.
- The production DB is read-only here. Maker documents live outside the
  repository (`~/research/motodiag/`); runs live in
  `~/.cache/motodiag/source-runs/`.
