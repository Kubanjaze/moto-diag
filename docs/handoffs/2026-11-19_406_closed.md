### Step 1: install the Mac's new steps on the home desktop (once)

**Which computer:** the home desktop. **Which window:** the Ubuntu
terminal. Run it after the pull request is merged. It asks for your Ubuntu
password once.

What it does, in order:
1. **Checks before changing anything:** this is the desktop, the Mac's way
   in is installed, the development copy of the code is clean, and master
   on GitHub holds this phase with the way in unchanged since.
2. **Puts the development copy of the code on master.**
3. **Installs the new list of steps and the password-free restarts.**
4. **Checks the installed list is the merged one, that exactly the
   approved restarts run without a password, and that nothing wider does.**

```bash
bash <<'EOF10'
set -u

  command -v "$T" >/dev/null 2>&1 || bad "this computer has no $T command; nothing was changed, so bring this to the advisor"
done
[ -d "$DEV/.git" ] || bad "this is not the home desktop's development checkout (run it on the home desktop, in the Ubuntu window); nothing was changed"
[ -f "$DISPATCHER" ] || bad "the Mac's way in is not installed here ($DISPATCHER is missing); nothing was changed, so bring this to the advisor"
[ -z "$(git -C "$DEV" status --porcelain --untracked-files=no </dev/null)" ] || bad "the development checkout has changes made by hand; nothing was changed, so bring this to the advisor"
```
