## What shipped

Live payments no longer wait on a public web address. The server stays
reachable only over the tailnet (K74).

- **`MOTODIAG_SHARE_LINKS_ENABLED=false` switches customer share links
  off.** Minting a link answers 403 with "Share links are switched off for
  now. You can still send the report as a PDF." Opening any link, old ones
  too (K79), answers a 404 page titled "Report links are off"; the link is
  not looked up, so no view is counted. Listing and revoking still work.
  Switched on again, every live link opens again: the switch changes no
  row.
- **With share links off, the live start-up check no longer asks for
  `MOTODIAG_PUBLIC_BASE_URL`**, and `motodiag serve` says so in one line.
  With them on (the default), the check is exactly as before.
- **`MOTODIAG_STRIPE_RETURN_PAGE_URL`** is one address for the six places
  Stripe sends a customer or a shop owner back to: after Checkout, the
  billing portal, an invoice payment, and Connect onboarding (two). Each
  takes it unless that one is set on its own. Empty (the default), the six
  keep their defaults.
- **The documents:** the README's settings table, the install guide, the
  API guide, the launch checklist, `docker-compose.yml`, and a new section
  of the payments guide, "The thank-you page".
- **F257 is closed.**
