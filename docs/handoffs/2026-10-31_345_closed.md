## What shipped

- **`motodiag backup run`**: one snapshot of live. The database is copied
  with SQLite's backup API (the API is never blocked), switched out of WAL
  mode, and refused if `pragma integrity_check` is not `ok`; each file is
  encrypted on the desktop (scrypt, AES-256-GCM, the passphrase never
  leaving `backup.env`) and put in the bucket. An upload goes once, as
  `media/<sha256>.enc`; the database goes whole each night as
  `snapshots/<UTC time>/motodiag.db.enc`, and the manifest last. One line
  per run in `~/backups/motodiag/offsite/runs.log`.
- **`list`, `restore --at <time|latest> --to <folder>`, `verify`,
  `status`.** A restore takes the newest snapshot at or before the time,
  checks every hash and the database's integrity, writes only into an
  empty folder, and refuses one that is, holds or lies under live's. A
  failed restore leaves nothing.
- **The S3 client is the standard library** (`backup/store.py`, SigV4):
  both of AWS's published worked examples reproduce their signatures.
  Nothing offsite is ever deleted: it has no delete call.
- **The desktop:** `ops/desktop/motodiag-backup.service` and `.timer`
  (03:00, a missed night runs at the next boot), `install_backup_unit.sh`.
  The `server` extra now installs `backup` (`cryptography`).
- **The guide:** `docs/guide/backups.md`, in plain English.

### The nightly backup: install it and prove it

**Which computer:** the home desktop. **Which window:** the Ubuntu
terminal. Paste this whole block once 345 is merged to `master`. It
brings the server's copy up to date and restarts the server, checks that
the key file is private (without showing it), installs the nightly timer
(it asks for your Ubuntu password once), takes the first copy now (this
can take several minutes the first time, because every upload goes),
lists the copies, reads the newest one back, and restores it into a new
folder of its own under `~/motodiag/` to check it.

```bash
bash <<'EOF2'
set -u
SRV=~/motodiag/server
ENVF=~/.config/motodiag/backup.env
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
git -C "$SRV" fetch -q origin master </dev/null || bad "could not fetch from GitHub"
git -C "$SRV" merge -q --ff-only origin/master </dev/null || bad "could not bring the server's copy up to date"
[ -f "$SRV/ops/desktop/install_backup_unit.sh" ] || bad "the server's copy does not have the backup code yet"
"$SRV/.venv/bin/python" -c "import cryptography, motodiag.backup.crypt" </dev/null || bad "the server cannot load the backup code; it may need: $SRV/.venv/bin/pip install -e '$SRV[server]'"
sudo -n systemctl restart motodiag-api.service || bad "could not restart the server"
echo "Restarting the server (up to 60 seconds)..."
for i in $(seq 30); do curl -s -o /dev/null http://127.0.0.1:8000/healthz && break; sleep 2; done
curl -s -o /dev/null http://127.0.0.1:8000/healthz || bad "the server did not come back"
[ -f "$ENVF" ] || bad "the key file $ENVF is missing"
[ "$(stat -c %a "$ENVF")" = "600" ] || bad "the key file must be private: run  chmod 600 $ENVF  and paste this again"
echo "Installing the nightly timer (your Ubuntu password)..."
sudo sh "$SRV/ops/desktop/install_backup_unit.sh" || bad "could not install the nightly timer"
systemctl list-timers motodiag-backup.timer | grep -q motodiag-backup.timer || bad "the nightly timer is not listed"
echo "Taking the first copy now (several minutes the first time)..."
sudo systemctl start motodiag-backup.service || bad "the first copy failed; see: journalctl -u motodiag-backup.service -n 30"
export PATH="$SRV/.venv/bin:$PATH"
export MOTODIAG_DB_PATH=~/motodiag/live/motodiag.db MOTODIAG_DATA_DIR=~/motodiag/live
motodiag backup status </dev/null || bad "the last copy did not work"
motodiag backup list </dev/null || bad "could not list the copies"
motodiag backup verify --at latest </dev/null || bad "the newest copy could not be read back"
TO=~/motodiag/restore_check_$(date +%Y%m%d_%H%M%S)
motodiag backup restore --at latest --to "$TO" </dev/null || bad "the restore into $TO failed"
CHECK=$("$SRV/.venv/bin/python" -c "import sqlite3,sys; print(sqlite3.connect(sys.argv[1]).execute('pragma integrity_check').fetchone()[0])" "$TO/motodiag.db")
echo "The restored copy's check: $CHECK"
[ "$CHECK" = "ok" ] || bad "the restored copy failed its check"
echo "The restored copy is in $TO (you may delete that folder)."
echo "ALL GOOD"
EOF2
```

Whoever merges copies the lines this prints (sizes, times and the ALL
