## What 258 learned that the next phase should not relearn

- **A gate's own Step 0 needs the controls its claims demand.** Two of
  this gate's Step 0 claims were false as written: "no adapter known"
  was measured against a database whose adapter catalogue was never
  seeded, and "no scooter row carries a DTC code" fell to 252's GROM125
  blink-code row, invisible to a `dtc_codes != ''` query that passes
  `'[]'`. The first `pytest` run was the control those claims never had.
  Recorded as the build's bug-fix register (#1–#4, one shared cause).
- **The mutation harness must revert only the mutation's known paths.**
  The first harness parsed `git status` to find what to revert and would
  have checked out real, uncommitted work alongside the mutation; the
  git error that stopped it is the only reason nothing was lost. The
  harness now reverts named paths only, and the build was committed
  before any mutation ran.
- **The junction's canonical spelling can differ from the model column's
  by a space** ("PCX 150" against "Honda PCX150") — a pin keyed on the
  model column's spelling counts 0 pairs where 12 live.
