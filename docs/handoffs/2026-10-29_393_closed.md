### After the merge: put the fleet on this code

**Which computer:** the home desktop. **Which window:** the Ubuntu
terminal. Paste this whole block once 393 is merged into `master`. It asks
for your password once (to restart the fleet), and checks that the fleet
came back with the weekly page armed.

```bash
bash <<'EOF2'
set -u
LOG=~/.local/state/motodiag/fleet/dispatcher.log
CODE=~/motodiag/fleet/code
VENV=~/.local/state/motodiag/fleet/venv
bad() { echo; echo "SOMETHING IS OFF: $1"; exit 1; }
if pgrep -x bwrap >/dev/null; then bad "the fleet is busy right now; wait 15 minutes and paste this again"; fi
git -C "$CODE" fetch -q origin master </dev/null || bad "could not fetch from GitHub"
git -C "$CODE" checkout -q master </dev/null || bad "could not switch the fleet to master"
git -C "$CODE" merge -q --ff-only origin/master </dev/null || bad "could not bring the fleet up to date"
grep -q "def stage_quality" "$CODE/.claude/skills/fleet/dispatcher.py" || bad "the fleet's copy does not have this phase's code yet (is 393 merged?)"
"$VENV/bin/ruff" --version | grep -q "0.16.9" || bad "the fleet's tools are not the pinned ones"
START=$(wc -l < "$LOG")
sudo systemctl restart motodiag-fleet.service || bad "could not restart the fleet"
echo "Restarting the fleet (up to 2 minutes)..."
for i in $(seq 60); do tail -n +$((START+1)) "$LOG" | grep -q "the weekly page starts with" && break; sleep 2; done
tail -n +$((START+1)) "$LOG" | grep -q "the weekly page starts with" || bad "the fleet did not come back with the weekly page"
echo "The fleet is on: $(git -C "$CODE" log -1 --oneline)"
echo "ALL GOOD"
EOF2
```
