## What shipped

- **`motodiag workflow run <slug> [--powertrain ice|electric|hybrid]`.**
  - It walks a template's checklist through Phase 82's step engine, one
    item at a time.
  - A required item takes `p` or `f`; an optional one takes `s` as well.
    Any other answer is asked again.
  - A fail prints the item's diagnosis at once.
  - A summary ends the run: passed, failed and skipped counts, then each
    failed item with its diagnosis, then "Nothing was saved".
  - Nothing is written and there is no schema change.
- **The powertrain (the operator's pick, option A):** `--powertrain`, or
  a prompt. A template that does not cover it is refused before item 1:
  `valve_adjustment_v1 covers ice, hybrid, not electric.`
- **Refusals match `workflow show`:** a retired starter prints its
  retirement line, an unknown slug its message, both exit 1, before any
  question.
- **The engine:** `DiagnosticWorkflow.stop_on_fail`, default `True`, so
  Phase 82's decision trees still end at a fail. A checklist sets it
  `False` (`workflows/runner.py`, `checklist_workflow`).
- **Tests:** `tests/test_phase356_workflow_run.py`, 32, through
  `CliRunner` with typed input on a `tmp_path` database. Every active
  template runs for each powertrain it covers and is refused for the
  rest. Each assertion helper is red on a planted output.
- **Mutations:** 11/11 red; `356_mutate.py` ships in the phase folder.
