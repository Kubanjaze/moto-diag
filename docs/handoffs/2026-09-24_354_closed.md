## What 354 learned that the next content phase should not relearn

- **A manual's file name is not its identity.** Three names in this phase
  came from file names or earlier rows, not from the documents: the
  "Symply 125" manual says only "MODEL ABA" (F150); the CHF50 manual never
  prints "Metropolitan"; the Zuma 125 manual prints only "YW125Y". Check
  the title page before attributing a figure to a model.
- **"The same copy Phase N cited" is a claim.** It was false for three of
  354's manuals. Say only what is known.
- **Year windows gate retrieval** (`_covers_year`, F132). A window must
  come from a document: the PCX150 row is 2013–2015 because the 2020
  PCX150 is a different engine (149 cm3), a fact a refuter found.
- **Refuters kill conditions, not headlines.** 30 of 170 claims died;
  none was a row's central finding. Most were a test condition dropped, a
  figure from the wrong chart, or a comparison between two different
  measurements.
- **zsh aborts an `&&` chain on an unmatched glob** and carries on after
  `;`. Scripts that touch a database run under `bash` with
  `set -euo pipefail` (354 phase log, "Deploy dry run").
- **Subconscious works again** (it was suspended during 257). `subc
  claude --model subconscious/glm-5.3-marathon -- -p … --tools ""` with
  257's flags; parse with `raw_decode`, cap answers (40 facts), forbid
  placeholders — two calls in 354 returned a truncated tail and a literal
  `[...]`.
