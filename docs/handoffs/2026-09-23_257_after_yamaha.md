## Two open Yamaha decisions (recommended answers)

### 1. YZF-R6, YZF-R7, MT-03: E4's main branch accepts `list_identity`

Their manuals never print the name. They print only model-year codes:
BN6-28199-13 "YZFR6L/YZFR6LC", D42-28199-10 "YZFR7T/YZFR7TC (R7)",
BRG-F8199-11 "MT03T/MT03TC". Each record pairs the PDF with the exact
name: "YZF-R6 - YZF600", "YZF-R7 - YZF690", "MT-03 - MTN320-A".
`list_identity` already serves E4's weak-spelling branch and
`model_scope`. It does not serve E4's main branch, "the document never
names the machine", which is where these three fail.

**Recommended:** let E4's main branch accept `list_identity` too. **No
year-letter parsing:** "M" is a year letter, and "YZFR1M" is also the
R1M, a different machine. Its own commit, with fixtures and break-it
(exact match only; "YZFR1M" still does not name the YZF-R1), then re-run
the three. A local E4 check first shows they would pass.

### 2. MT-09, MT-07: one fetch each of Yamaha Motor Europe's pages

**Measured on the US side.** Yamaha's US 2026 MT-09 and MT-07 pages
(`acquired/Yamaha/models_mt-09.html`, `models_mt-07.html`) have 0 hits
for Y-AMT, "automated manual" or "clutchless". The US MT line is MT-03,
MT-07, MT-09, MT-09 SP, MT-10 and MT-10 SP. The US manual library's 155
names include no Y-AMT, and neither 2026 manual mentions it. The
sentence first cited for the Y-AMT was our own E12 fixture
(`tests/test_phase257_source_checks.py:604`), not a Yamaha page.

**Recommended:** one fetch each of Yamaha Motor Europe's MT-09 and MT-07
pages, no model call. If Yamaha names a Y-AMT for the model, put it in
`AMBIGUOUS_MODELS` as {manual, semi_auto_actuated}, citing that page and
the owner's manual (the Honda DCT treatment). If not, write it manual
from its owner's manual. The Europe host is not in `MAKER_HOSTS`; adding
it is an E11 decision to record. Both are E4-withheld today (they print
"MT09T/MT09TC", "MT07T/MT07TC"), so the manual write also needs
decision 1.

## Worth knowing before KTM

- A run can stop on a transient network error (`Yamaha_20260923_202956`:
  ENOTFOUND, nothing written). A retry is a new run.
- Real-file tests read the whole library (about 100 s per `candidates`
  pass). Compute once per class.
- Two break-its this session survived because they were not real breaks:
  a redundant accent filter, and a renamed canonical that still resolved
  through its aliases. The log records both and the real break that
  replaced each.
- A grep with no word boundary gave a wrong measurement ("YZFR6" inside
  "YZFR6L"). Measure names with whole-word patterns.
