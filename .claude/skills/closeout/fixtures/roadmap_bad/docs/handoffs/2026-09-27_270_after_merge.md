# Known-bad for R8: operator paste blocks whose gh calls name no repository

The real case first, as 390's handoff first had it (2026-10-26, F222):

```bash
bash <<'X'
bad() { echo "SOMETHING IS OFF: $1"; exit 1; }
gh issue edit 14 --remove-label needs-admiral </dev/null >/dev/null || bad "could not take the hold off issue 14"
echo "ALL GOOD"
X
```

A cd that is not into the repository:

```bash
cd /tmp && gh pr view 3 --json state && echo "ALL GOOD"
```

An api path with the placeholders gh fills from the working directory:

```bash
N=$(gh api 'repos/{owner}/{repo}/issues' --jq length) && echo "ALL GOOD $N"
```
